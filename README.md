## Personalize before publishing

1. Replace the `YOUR PHOTO` placeholder in `index.html` with your professional photo if desired.
2. Replace broad GitHub profile links with direct project repository URLs when the repositories are ready.
3. Add a resume link/button once your final PDF is available.
4. Update skill percentages to match your actual confidence level.
5. Verify all internship/certificate wording and dates before publishing.

## Deploy

### GitHub Pages

1. Create a public repository such as `aniketrajj.github.io`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Select deployment from the `main` branch and root folder.

### Vercel

Import the repository or upload this static folder. No build step is required.

## Files
